Good Timer is a versatile timer app for everyday life. It provides a customizable interval timer and a stopwatch with lap recording, perfect for studying, exercising, cooking, meditation, and more.

Timer

Basic Concept

The timer consists of phases and rounds.

  • Phase: A segment with a name and duration (e.g., "Focus" 25 min, "Break" 5 min)
  • Round: How many times to repeat the entire phase sequence
  • Up to 10 phases can be added

Example: Focus (25 min) → Break (5 min), repeated for 4 rounds

Timer Screen

The timer screen has two tabs.

Timer Tab

  • Circular countdown display
  • Current phase name and remaining time
  • Round progress (e.g., "Round 2/4")
  • Start, Pause, Resume, Stop buttons

Settings Tab

  • Edit phase list (name, duration, color)
  • Add/remove/reorder phases
  • Adjust number of rounds
  • "Save as Preset" button

Timer Controls

IdleStart
RunningPause
PausedResume, Stop
StoppedReset, Start

Round Settings

  • Finite rounds: Repeat 1–999 times
  • Infinite rounds: Repeat until manually stopped

Presets

A preset is a saved timer configuration (phases + rounds) for quick reuse.

Managing Presets

  • Tap the preset icon at the top of the timer screen
  • Add: Tap the + button to create a new preset
  • Apply: Tap a preset to load it into the timer
  • Edit: Tap the edit icon
  • Copy: Tap the copy icon to duplicate
  • Delete: Tap the delete icon, then confirm
  • Favorite: Tap the star icon to pin to the top

Default Presets

The following presets are created automatically on first launch:

  • Pomodoro (Focus 25 min + Break 5 min, 4 rounds)
  • Tabata (Exercise 20 sec + Rest 10 sec, 8 rounds)
  • Study 50/10 (Study 50 min + Break 10 min, 3 rounds)
  • Stretching (Exercise 30 sec + Rest 15 sec, 10 rounds)
  • Meditation (Preparation 1 min + Meditation 10 min + Wrap Up 1 min, 1 round)
  • 5-4-3-2-1 Countdown (5 min → 4 min → 3 min → 2 min → 1 min, 1 round)
  • Cooking (Cooking 10 min + Simmering 5 min, 1 round)
  • Presentation (Presentation 15 min + Q&A 5 min, 1 round)

Stopwatch

Basic Usage

  1. Go to the Stopwatch tab
  2. Tap Start
  3. Tap Lap while running to record splits
  4. Tap Stop to finish
  5. The session is automatically saved

Lap Recording

  • Tap the Lap button during timing to record a split
  • Fastest and slowest laps are highlighted
  • Tap the lap list after stopping to view detailed records

Labels

Assign labels to stopwatch sessions for categorization.

  • Tap the label chip above the timer to select or create a label
  • Recently used labels appear at the top
  • Long press a label to delete it (records are kept)

Today's History

The second tab on the Stopwatch screen lets you quickly view sessions recorded today.

  • Only stopwatch records created today are displayed
  • Shows label, date/time, and total elapsed time
  • Tap a session to view detailed lap records

History

View timer and stopwatch usage history in the History tab.

Time Period

  • Today
  • This Week
  • This Month
  • All Time
  • Custom (date range picker)

Timer History

  • Total sessions
  • Total active time
  • Total completed rounds
  • Detailed breakdown per session (phases, rounds, durations)

Stopwatch History

  • Total sessions
  • Total elapsed time
  • Total laps
  • Detailed lap records per session

Deleting Records

  • Individual session: swipe left or long press
  • Delete all: tap the delete button at the top right

Settings

Theme

  • System Default: Follows device settings
  • Light Mode: Light background
  • Dark Mode: Dark background

Language

  • Auto (follows device locale)
  • English, Korean, Japanese, Chinese

Sound & Vibration

  • Sound: Alert on phase transitions (on/off)
  • Vibration: Haptic feedback on phase transitions (on/off)

Screen

  • Keep Screen On: Prevents the screen from turning off while the timer or stopwatch is running

Cloud Sync

Back up and sync your data via Google Drive.

Before signing in:

  • Sign in with Google button
  • Restore from backup file (.gz or .json from device)

After signing in:

  • Connected Google account displayed
  • Auto Sync: Automatically backs up when data changes
  • Sync Now: Manual immediate sync
  • Reset Cloud: Delete cloud data and re-upload from device
  • Sign Out: Disconnect Google account
