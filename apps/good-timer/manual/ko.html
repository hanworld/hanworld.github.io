Good Timer는 일상의 모든 순간에 함께하는 범용 타이머 앱입니다. 자유롭게 구성할 수 있는 인터벌 타이머와 랩 기록이 가능한 스톱워치를 제공하며, 학습, 운동, 요리, 명상 등 다양한 활동에 활용할 수 있습니다.

화면 구성

앱 하단(세로 모드) 또는 좌측(가로 모드)의 탭으로 화면을 전환합니다.

타이머

기본 개념

타이머는 페이즈(구간)와 라운드(반복)로 구성됩니다.

  • 페이즈: 이름과 시간이 있는 하나의 구간 (예: "집중" 25분, "휴식" 5분)
  • 라운드: 전체 페이즈 순서를 몇 번 반복할지 설정
  • 페이즈는 최대 10개까지 추가 가능

예시: 집중(25분) → 휴식(5분) 을 4라운드 반복

타이머 화면

타이머 화면은 두 개의 탭으로 구성됩니다.

타이머 탭

  • 원형 카운트다운 디스플레이
  • 현재 페이즈 이름과 남은 시간
  • 라운드 진행 상황 (예: "라운드 2/4")
  • 시작, 일시정지, 재개, 정지 버튼

설정 탭

  • 페이즈 목록 편집 (이름, 시간, 색상)
  • 페이즈 추가/삭제/순서 변경
  • 라운드 수 조정
  • "프리셋으로 저장" 버튼

타이머 조작

대기시작
실행 중일시정지
일시정지재개, 정지
정지됨리셋, 시작
완료리셋, 시작

라운드 설정

  • 유한 라운드: 1~999회 반복
  • 무한 라운드: 수동으로 정지할 때까지 반복

프리셋

프리셋은 자주 사용하는 타이머 구성(페이즈 + 라운드)을 저장한 것입니다.

프리셋 관리

  • 타이머 화면 상단의 프리셋 아이콘을 탭하여 목록 확인
  • 추가: + 버튼으로 새 프리셋 생성
  • 적용: 프리셋을 탭하여 타이머에 적용
  • 편집: 편집 아이콘 탭
  • 복사: 복사 아이콘으로 복제
  • 삭제: 삭제 아이콘 탭 후 확인
  • 즐겨찾기: 별 아이콘으로 상단 고정

기본 프리셋

최초 설치 시 다음 프리셋이 자동 생성됩니다:

  • 뽀모도로 (집중 25분 + 휴식 5분, 4라운드)
  • 타바타 (운동 20초 + 휴식 10초, 8라운드)
  • 학습 50/10 (학습 50분 + 휴식 10분, 3라운드)
  • 스트레칭 (운동 30초 + 휴식 15초, 10라운드)
  • 명상 (준비 1분 + 명상 10분 + 마무리 1분, 1라운드)
  • 5-4-3-2-1 카운트다운 (5분 → 4분 → 3분 → 2분 → 1분, 1라운드)
  • 요리 (조리 10분 + 뜸들이기 5분, 1라운드)
  • 프레젠테이션 (발표 15분 + 질의응답 5분, 1라운드)

스톱워치

기본 사용법

  1. 스톱워치 탭으로 이동
  2. 시작 버튼 탭
  3. 실행 중 랩 버튼으로 구간 기록
  4. 정지 버튼으로 종료
  5. 기록이 자동 저장됨

랩 기록

  • 실행 중 랩 버튼을 탭하면 구간 시간이 기록됩니다
  • 가장 빠른 랩과 가장 느린 랩이 표시됩니다
  • 정지 후 랩 목록을 탭하면 상세 기록을 확인할 수 있습니다

라벨

스톱워치 세션에 라벨을 지정하여 분류할 수 있습니다.

  • 타이머 위의 라벨 칩을 탭하여 선택/생성
  • 최근 사용한 라벨이 상단에 표시됩니다
  • 라벨 길게 누르면 삭제 가능 (기록은 유지)

오늘의 기록

스톱워치 화면의 두 번째 탭에서 오늘 기록한 세션을 바로 확인할 수 있습니다.

  • 오늘 생성된 스톱워치 기록만 표시됩니다
  • 라벨, 날짜/시간, 총 경과 시간이 표시됩니다
  • 탭하면 랩 상세 기록을 확인할 수 있습니다

기록

기록 탭에서 타이머와 스톱워치 사용 이력을 확인할 수 있습니다.

조회 기간

  • 오늘
  • 이번 주
  • 이번 달
  • 전체
  • 사용자 지정 (날짜 범위 선택)

타이머 기록

  • 총 세션 수
  • 총 활동 시간
  • 총 완료 라운드 수
  • 세션별 상세 기록 (페이즈, 라운드, 시간)

스톱워치 기록

  • 총 세션 수
  • 총 측정 시간
  • 총 랩 수
  • 세션별 랩 상세 기록

기록 삭제

  • 개별 세션: 좌측으로 스와이프 또는 길게 누르기
  • 전체 삭제: 우측 상단 삭제 버튼

설정

테마

  • 시스템 기본: 기기 설정에 따름
  • 라이트 모드: 밝은 배경
  • 다크 모드: 어두운 배경

언어

  • 자동 (기기 설정에 따름)
  • 한국어, English, 日本語, 中文

소리 및 진동

  • 소리: 페이즈 전환 시 알림음 (켜기/끄기)
  • 진동: 페이즈 전환 시 진동 (켜기/끄기)

화면

  • 화면 켜짐 유지: 타이머/스톱워치 실행 중 화면이 꺼지지 않음

클라우드 동기화

Google Drive를 통해 데이터를 백업하고 동기화할 수 있습니다.

로그인 전:

  • Google 로그인 버튼
  • 백업 파일에서 복원 (기기의 .gz 또는 .json 파일)

로그인 후:

  • 연결된 Google 계정 표시
  • 자동 동기화: 데이터 변경 시 자동 백업
  • 지금 동기화: 수동으로 즉시 동기화
  • 클라우드 초기화: 클라우드 데이터 삭제 후 재업로드
  • 로그아웃: Google 계정 연결 해제

앱 개발 응원하기

인앱 결제로 개발을 응원할 수 있습니다. 응원하면 광고가 제거됩니다.

  • 작은 응원
  • 따뜻한 응원
  • 큰 응원

Windows에서는 인앱 결제를 사용할 수 없습니다.

  • 페이즈별로 다른 색상을 설정하면 타이머 진행 상황을 한눈에 파악할 수 있습니다
