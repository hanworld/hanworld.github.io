Minewise 是一款无需猜测的扫雷益智游戏：只靠数字线索避开地雷，打开所有不是地雷的格子。每个盘面都从发光的起始格开始，不用猜，只靠逻辑就能一路解到最后。

  • 踩到地雷也不会结束盘面（困难模式除外）。踩到的格子会留下爆炸的地雷，只会增加失误。提示不限次数、免费使用，也没有时间限制。
  • 无需注册，也无需登录。第一次打开时，会先用一个7×7的小盘面进行新手教程，带你熟悉规则。点击跳过可以随时结束。
  • 没有网络也能玩。 只有屏幕下方的广告，以及发送使用统计和错误报告时才会用到网络。
  • 语言跟随设备设置。支持中文（简体、繁体）、英语、韩语、日语，也可以在设置中直接选择。

1. 规则

  • 盘面是纵横排列的方形格子，其中一部分藏着地雷。每个盘面的地雷数是固定的，并显示在屏幕上。
  • 打开不是地雷的格子，会显示周围八个格子里的地雷数。如果是0，就不显示数字而是空白格，并自动打开周围的格子（空白格连在一起时会一直打开下去）。
  • 旗子插在你认为是地雷的格子上。插了旗子的格子，点击也不会打开。
  • 打开所有不是地雷的格子，就通关了。不必把地雷都插上旗子。
  • 每个盘面都有一个发光的起始格。起始格总是空白格，所以一开始会打开一大片。一开始只能点击这一格（点击其他格子会提示“请先打开发光的格子”）。
  • 每个盘面都能从起始格到最后，只靠数字、不用猜就解开。不会出现不猜就打不开的局面。
  • 踩到地雷也不会结束（困难模式除外，见第6章）。踩到的格子会留下爆炸的地雷，失误增加一次。没有撤销。如果旗子插错了还点击数字一次打开（见第3章），地雷会被打开，打开几个地雷就算几次失误。
  • 最佳纪录只计算没有失误的盘面。 没有失误也没有使用提示就通关时，结果上会盖上完美印章。

盘面怎么看

  • 未打开的格子是凸起的绿色方块，已打开的格子颜色较浅、位置较低。数字按大小各有不同的颜色。
  • 发光的格子是起始格。提示告诉你下一步要打开哪一格时，也会用同样的光。
  • 旗子是琥珀色（偏橙的黄色）。
  • 踩到的地雷显示为红色格子，上面有地雷图案和虚线圆环。不只靠颜色，也用形状提示。
  • 插错的旗子（插在不是地雷的格子上的旗子）上会叠一个奶油色的 X。开启立即显示失误时、提示指出它时、困难模式的盘面结束时可以看到。
  • 盖着琥珀色罩子的数字和围着琥珀色框的格子，是提示推理所依据的内容（见第4章）。

2. 解题要点

教程用一个7×7的盘面，分五步教你基础：起始格 → 数字与插旗 → 一次打开 → 两个数字 → 独立完成。每一步都会让要看的数字和地雷亮起，只有该点击的格子才有反应。提示会用名称告诉你用了哪种要点：一个数字、两个数字、多个数字、剩余地雷数、所有布雷方式。它们的意思如下。

  • 一个数字：已打开格子上的数字，是周围八个格子里的地雷数。如果周围未打开的格子数等于还没找到的地雷数，这些格子就全是地雷（1的周围只有一个未打开的格子时，那一格就是地雷）。反过来，如果周围的地雷已经全部找到，其余未打开的格子就是安全的。把找到的地雷插上旗子会很方便。
  • 两个数字：把相邻的两个数字放在一起看。例如，上面的1周围未打开的格子都在下面的1的周围，那么上面的1的地雷就在两个数字共同挨着的格子里，这颗地雷也正是下面的1的地雷。所以只挨着下面的1的格子是安全的。数字不同时，要推算共同挨着的格子里该有几颗地雷。
  • 多个数字：把多个数字放在一起看，想想满足所有数字的布雷方式。有些格子在任何一种方式中都安全（或都是地雷）。
  • 剩余地雷数：整个盘面的剩余地雷数也是线索。地雷全部找到时，其余格子都是安全的；剩余地雷数等于未打开的格子数时，它们全是地雷。如果一个数字（或几个数字）用掉了全部剩余地雷，其他未打开的格子就是安全的。
  • 所有布雷方式：需要把未打开格子的所有布雷方式都考虑一遍，这种情况非常少见。

等级1的盘面只靠一个数字和两个数字就能解开。从等级2起，有些盘面还需要多个数字和剩余地雷数。更难的要点，会由提示连同理由一起告诉你（见第4章）。

3. 操作

  • 一开始只能点击发光的起始格。打开它之后，计时开始。
  • 点击：点击未打开的格子就会打开它。手指抬起时才确定，按住时手指下的格子会亮起。手指拖动较远时不会打开（视为想移动盘面）。
  • 长按（操作 A，默认）：长按未打开的格子会插旗，长按已插旗的格子会拔掉。按住时圆环会逐渐变满，变满时旗子就插上了。长按时间在设置中选择（默认 350 毫秒）。
  • [打开|插旗]按钮（操作 B）：在设置的操作中选择[打开|插旗]按钮后，盘面下方会出现[打开|插旗]按钮。选中[打开]时，点击格子就打开它；选中[插旗]时，点击未打开的格子会插上或拔掉旗子。此时不使用长按。
  • 点击数字打开周围（默认开启）：点击已打开的数字，当它周围的旗子数（含踩到的地雷）与数字相同时，会一次打开周围所有未打开的格子。如果旗子插错了，地雷会被打开，打开几个地雷就算几次失误。旗子数不同时不会打开。
  • 缩放与移动：所有盘面都可以用两指张开、捏合来放大缩小，并拖动来移动。12×20 及以上的大盘面（等级4、5）一开始会稍微放大，并把发光的起始格放在正中间。出现第二根手指时，这一次点击会被丢弃，所以缩放时的手指不会打开格子或插旗。
  • 拔掉旗子要再次长按（操作 B 则选中[插旗]后再点击一次）。

4. 提示

提示按钮会告诉你下一个要打开的格子，并说明理由。提示不限次数，免费使用（困难模式除外）。打开起始格之后才能使用。

同一个按钮要按三次：提示 → 查看格子 → 采用。

  • 第一步：点击提示，只会告诉你要看的地方。作为依据的数字会盖上琥珀色的罩子，它们所依靠的地雷（已经能找出的地雷）会用琥珀色的框和点标出（例如“把两个高亮的数字放在一起看。有可以打开的格子”。有所依靠的地雷时，会加上“带框的格子是地雷”）。气泡上的名称是所用的要点（一个数字、两个数字、多个数字、剩余地雷数、所有布雷方式）。
  • 第二步：按钮变成查看格子。点击后，要打开的格子会发光，并给出理由（例如“上面的1周围未打开的格子也都挨着下面的1。所以只挨着下面的1的格子是安全的”）。两个数字相同时，会用上、下、左、右这样的位置词来区分。
  • 第三步：按钮变成采用。点击后，会在所依靠的地雷上插旗（如果还没插），并打开那个格子。
  • 如果有插错的旗子，会先指出它（名称插错的旗）。从最先插的开始，并在那面旗子上叠一个 X。按钮会直接变成采用，点击后拔掉那面旗子。
  • 提示只根据已打开的格子和踩到的地雷来推理。它不把旗子当作依据，所以即使一面旗子也没插，或者旗子插错了，提示也永远是对的。旗子只用来指出插错的旗，以及优先选出依靠已插旗地雷的格子。给出的格子是容易推出的格子（依靠的地雷少，要点也简单）。
  • 用过的提示次数会显示在盘面上方一行和结果里，也会写进 Daily 的分享文字。请求提示时（第一步）算一次；进入第二步或采用不另算，关闭后再请求会多算一次。
  • 点击气泡上的关闭（X），或者打开格子、插旗，提示就会关闭。

5. 辅助功能与盘面设置

在设置的操作和盘面中开关。游戏中可以用快捷设置马上更改。

  • 点击数字打开周围（默认开启）：点击已打开的数字，如果周围的旗子数与数字相同，就会打开其余未打开的格子（见第3章）。关闭后，点击数字没有任何反应。
  • 立即显示失误（默认关闭）：马上在插错的旗子（插在不是地雷的格子上的旗子）上标出 X。困难模式不使用。关闭时，插错的旗子要等提示指出才会告诉你。
  • 显示时间（默认开启）：在盘面上方显示时间。关闭后只是不显示，时间仍在计算。通关盘面的用时会显示在结果里。
  • 大号数字（默认关闭）：把盘面上的数字画大一些。
  • 长按时间(毫秒)（默认 350）：从 250、300、350、400、500 中选择。只在“点击 · 长按”的操作方式下使用。

6. 模式

Classic — 自选等级，不限时

  • 在主页 Classic 卡片上方的切换中选中 Classic，在分页（1～5）中选择等级，点击开始。有进行中的盘面时会显示继续。第一次玩建议从等级1开始。
  • 等级按盘面大小（横×纵）和地雷数划分。等级越高，盘面越大，地雷越多。所有等级一开始就开放。

  • 分页上显示等级编号和盘面大小。卡片中间的盘面预览显示正在解的盘面的样子（已打开的格子、旗子、踩到的地雷；不画数字），向两侧滑动可以切换到下一个或上一个等级。下面一行显示所选等级和一行记录（例如“等级3 · 12×16 · 地雷36”，“最佳 03:41 · 通关 12 · 完美 3”）。
  • 盘面会从还没通关的盘面里随机出。通关过的盘面不会再出现；某个等级的盘面全部通关后，会从最早通关的那一局开始再出。
  • 通关后，结果卡片会显示用时、失误、提示、最佳（超过原来的纪录时会盖上新纪录印章）和通关的盘面数。没有失误也没有使用提示时会盖上完美印章，有失误时会提示“有失误的盘面不计入最佳纪录”。点击下一局会接着出同一等级的下一局。
  • 进行中的盘面会自动保存。离开或重新打开应用后，每个等级都能接着解。离开应用期间不计时。如果在打开起始格之前离开，同一个盘面会原样等着你。

困难 — 踩到地雷就结束

  • 在主页 Classic 卡片上方的[Classic | 困难]切换中选中困难，就用经典规则解同样的五个等级（上表的盘面大小和地雷数）。选中困难后，所选等级的分页和下面的按钮会变成深色底、琥珀色边框的困难样式，按钮变成挑战（有进行中的盘面时为继续）。Classic 和困难看的是同一个等级。
  • 踩到地雷，这一局就结束了（失败）。所有藏着的地雷都会显示出来，插错的旗子上会有 X。结果会显示“踩到地雷了”和已打开的安全格的比例。
  • 没有提示。 盘面下方一行没有提示按钮，取而代之的是“踩到地雷就结束 · 没有提示”的条。立即显示失误也不使用。点击数字打开周围仍然可用（旗子插错时地雷会被打开，算失败）。
  • 盘面数量没有限制。点击结果里的下一局就能接着玩。在困难模式中结束的盘面（成功或失败）不会再出现，在 Classic 中进行到一半的盘面也会尽量避开。
  • 中途离开不算失败。每个等级正在解的盘面会保存下来，之后可以接着解。
  • 重来面板里只有新的一局（把同一局从头开始，就会带着已经看过的格子开始）。打开起始格之后选择新的一局，这一局会记为失败。 面板里也这样写着。打开起始格之前不计。
  • 结果卡片会显示最佳（只算成功的盘面，超过原来的纪录时盖上新纪录印章）、连续成功、成功率和成功（成功的盘面/结束的盘面）。记录画面里也按等级汇总（见第7章）。分享只有 Daily 才有。

Daily — 今天的三个盘面

  • 每天所有人拿到同样的三个盘面：小盘面（9×9 · 地雷10）、中盘面（12×16 · 地雷36）、大盘面（16×30 · 地雷99）。全世界的人在同一天解同样的盘面（以设备日期为准）。新的 Daily 会在设备时间的零点开放。
  • 每个盘面分开解，结果也各自保存。规则和 Classic 一样（失误不会结束盘面，提示不限次数）。盘面不会以失败告终，所以没有失败。
  • 没有时间限制，到目前为止的用时显示在盘面上方（可以在设置中隐藏）。
  • 当天之内离开再回来也能接着解。即使选择这一局从头开始，当天的用时、失误和提示也会继续累计（重来时只有这一项）。日期变了以后，没解完的昨天的盘面会消失，新的盘面会开放。
  • 当天的三个盘面只要通关其中一个，这一天就计入连续；中间空一天就会中断。
  • 主页的 Daily 卡片会显示编号和日期（例如 #12 · 10月22日）、连续天数、今天的三个盘面和这一周的七天。每个盘面的格子上显示盘面名称、大小和状态（未开始、继续，通关的盘面显示对勾和用时），点击后可以开始解，或查看已通关盘面的结果。这一周的七天显示星期、日期和当天三个盘面的圆点（通关的盘面是实心圆点，今天是粗边框）。
  • 结果画面会显示盘面大小、用时、失误、提示、连续（天数）、这一周的七天和距下次 Daily 的时间。没有失误也没有使用提示时会盖上完美印章，超过最长连续时，连续一栏会盖上新纪录印章。可以用分享发送结果（一次一个盘面）。例如：
Minewise Daily 小盘面 #12 ✅ 03:41
失误 0 · 提示 1
🔥 连续5天

#12是 Daily 的编号，旁边是用时（分:秒，超过一小时则为时:分:秒）。第一行的“Minewise Daily”在任何语言中都一样，并写上盘面种类，方便解同一个盘面的人互相比较。第二行是失误和提示的次数，第三行是连续记录（两天以上才显示）。第一个 Daily 是 #1，之后每天加一，编号相同就是同样的盘面。

7. 记录

点击主页右上角的奖杯按钮打开。按钮上会显示通关的盘面数。

  • 最上方：通关盘面总数（Classic、困难和 Daily）的合计，以及 Classic、困难、Daily 各自的数量
  • Classic：各等级（盘面大小）的通关数、最佳用时（只计算没有失误的盘面）、平均用时和完美盘面数（没有失误也没有使用提示的盘面）。还没有通关的等级会变淡，用时显示为“-”。
  • 困难：各等级的成功（成功的盘面/结束的盘面）、成功率、最佳用时（只算成功的盘面）和最佳连续（最长的连续成功）
  • Daily：连续、最长连续、通关天数、通关盘面。下方的日历（用两侧的箭头按月翻页）会用实心圆标出通关的日子，今天会有边框。

8. 设置

点击主页右上角的齿轮打开。分为四组。游戏中可以用快捷设置按钮马上更改前三组。
