應用程式名稱Minewise
版本1.0.1
開發Willee Project
支援平台Android

Minewise 是一款無需猜測的踩地雷益智遊戲：只靠數字線索避開地雷，打開所有不是地雷的格子。每個盤面都從發光的起始格開始，不用猜，只靠邏輯就能一路解到最後。

  • 踩到地雷也不會結束盤面（困難模式除外）。踩到的格子會留下爆炸的地雷，只會增加失誤。提示不限次數、免費使用，也沒有時間限制。
  • 不需要註冊，也不需要登入。第一次打開時，會先用一個7×7的小盤面進行新手教學，帶你熟悉規則。點擊略過可以隨時結束。
  • 沒有網路也能玩。 只有畫面下方的廣告，以及傳送使用統計和錯誤報告時才會用到網路。
  • 語言跟隨裝置設定。支援中文（繁體、簡體）、英文、韓文、日文，也可以在設定中直接選擇。

1. 規則

  • 盤面是縱橫排列的方形格子，其中一部分藏著地雷。每個盤面的地雷數是固定的，並顯示在畫面上。
  • 打開不是地雷的格子，會顯示周圍八個格子裡的地雷數。如果是0，就不顯示數字而是空白格，並自動打開周圍的格子（空白格連在一起時會一直打開下去）。
  • 旗子插在你認為是地雷的格子上。插了旗子的格子，點擊也不會打開。
  • 打開所有不是地雷的格子，就過關了。不必把地雷都插上旗子。
  • 每個盤面都有一個發光的起始格。起始格總是空白格，所以一開始會打開一大片。一開始只能點擊這一格（點擊其他格子會提示「請先打開發光的格子」）。
  • 每個盤面都能從起始格到最後，只靠數字、不用猜就解開。不會出現不猜就打不開的局面。
  • 踩到地雷也不會結束（困難模式除外，見第6章）。踩到的格子會留下爆炸的地雷，失誤增加一次。沒有復原。如果旗子插錯了還點擊數字一次打開（見第3章），地雷會被打開，打開幾個地雷就算幾次失誤。
  • 最佳紀錄只計算沒有失誤的盤面。 沒有失誤也沒有使用提示就過關時，結果上會蓋上完美印章。

盤面怎麼看

  • 未打開的格子是凸起的綠色方塊，已打開的格子顏色較淺、位置較低。數字依大小各有不同的顏色。
  • 發光的格子是起始格。提示告訴你下一步要打開哪一格時，也會用同樣的光。
  • 旗子是琥珀色（偏橙的黃色）。
  • 踩到的地雷顯示為紅色格子，上面有地雷圖案和虛線圓環。不只靠顏色，也用形狀提示。
  • 插錯的旗子（插在不是地雷的格子上的旗子）上會疊一個奶油色的 X。開啟立即顯示失誤時、提示指出它時、困難模式的盤面結束時可以看到。
  • 蓋著琥珀色罩子的數字和圍著琥珀色框的格子，是提示推理所依據的內容（見第4章）。

2. 解題要點

教學用一個7×7的盤面，分五步教你基礎：起始格 → 數字與插旗 → 一次打開 → 兩個數字 → 獨立完成。每一步都會讓要看的數字和地雷亮起，只有該點擊的格子才有反應。提示會用名稱告訴你用了哪種要點：一個數字、兩個數字、多個數字、剩餘地雷數、所有佈雷方式。它們的意思如下。

  • 一個數字：已打開格子上的數字，是周圍八個格子裡的地雷數。如果周圍未打開的格子數等於還沒找到的地雷數，這些格子就全是地雷（1的周圍只有一個未打開的格子時，那一格就是地雷）。反過來，如果周圍的地雷已經全部找到，其餘未打開的格子就是安全的。把找到的地雷插上旗子會很方便。
  • 兩個數字：把相鄰的兩個數字放在一起看。例如，上面的1周圍未打開的格子都在下面的1的周圍，那麼上面的1的地雷就在兩個數字共同挨著的格子裡，這顆地雷也正是下面的1的地雷。所以只挨著下面的1的格子是安全的。數字不同時，要推算共同挨著的格子裡該有幾顆地雷。
  • 多個數字：把多個數字放在一起看，想想滿足所有數字的佈雷方式。有些格子在任何一種方式中都安全（或都是地雷）。
  • 剩餘地雷數：整個盤面的剩餘地雷數也是線索。地雷全部找到時，其餘格子都是安全的；剩餘地雷數等於未打開的格子數時，它們全是地雷。如果一個數字（或幾個數字）用掉了全部剩餘地雷，其他未打開的格子就是安全的。
  • 所有佈雷方式：需要把未打開格子的所有佈雷方式都考慮一遍，這種情況非常少見。

等級1的盤面只靠一個數字和兩個數字就能解開。從等級2起，有些盤面還需要多個數字和剩餘地雷數。更難的要點，會由提示連同理由一起告訴你（見第4章）。

3. 操作

  • 一開始只能點擊發光的起始格。打開它之後，計時開始。
  • 點擊：點擊未打開的格子就會打開它。手指抬起時才確定，按住時手指下的格子會亮起。手指拖動較遠時不會打開（視為想移動盤面）。
  • 長按（操作 A，預設）：長按未打開的格子會插旗，長按已插旗的格子會拔掉。按住時圓環會逐漸變滿，變滿時旗子就插上了。長按時間在設定中選擇（預設 350 毫秒）。
  • [打開|插旗]按鈕（操作 B）：在設定的操作中選擇[打開|插旗]按鈕後，盤面下方會出現[打開|插旗]按鈕。選中[打開]時，點擊格子就打開它；選中[插旗]時，點擊未打開的格子會插上或拔掉旗子。此時不使用長按。
  • 點擊數字打開周圍（預設開啟）：點擊已打開的數字，當它周圍的旗子數（含踩到的地雷）與數字相同時，會一次打開周圍所有未打開的格子。如果旗子插錯了，地雷會被打開，打開幾個地雷就算幾次失誤。旗子數不同時不會打開。
  • 縮放與移動：所有盤面都可以用兩指張開、捏合來放大縮小，並拖動來移動。12×20 及以上的大盤面（等級4、5）一開始會稍微放大，並把發光的起始格放在正中間。出現第二根手指時，這一次點擊會被丟棄，所以縮放時的手指不會打開格子或插旗。
  • 拔掉旗子要再次長按（操作 B 則選中[插旗]後再點擊一次）。

4. 提示

提示按鈕會告訴你下一個要打開的格子，並說明理由。提示不限次數，免費使用（困難模式除外）。打開起始格之後才能使用。

同一個按鈕要按三次：提示 → 查看格子 → 套用。

  • 第一步：點擊提示，只會告訴你要看的地方。作為依據的數字會蓋上琥珀色的罩子，它們所依靠的地雷（已經能找出的地雷）會用琥珀色的框和點標出（例如「把兩個標亮的數字放在一起看。有可以打開的格子」。有所依靠的地雷時，會加上「帶框的格子是地雷」）。氣泡上的名稱是所用的要點（一個數字、兩個數字、多個數字、剩餘地雷數、所有佈雷方式）。
  • 第二步：按鈕變成查看格子。點擊後，要打開的格子會發光，並給出理由（例如「上面的1周圍未打開的格子也都挨著下面的1。所以只挨著下面的1的格子是安全的」）。兩個數字相同時，會用上、下、左、右這樣的位置詞來區分。
  • 第三步：按鈕變成套用。點擊後，會在所依靠的地雷上插旗（如果還沒插），並打開那個格子。
  • 如果有插錯的旗子，會先指出它（名稱插錯的旗）。從最先插的開始，並在那面旗子上疊一個 X。按鈕會直接變成套用，點擊後拔掉那面旗子。
  • 提示只根據已打開的格子和踩到的地雷來推理。它不把旗子當作依據，所以即使一面旗子也沒插，或者旗子插錯了，提示也永遠是對的。旗子只用來指出插錯的旗，以及優先選出依靠已插旗地雷的格子。給出的格子是容易推出的格子（依靠的地雷少，要點也簡單）。
  • 用過的提示次數會顯示在盤面上方一行和結果裡，也會寫進 Daily 的分享文字。請求提示時（第一步）算一次；進入第二步或套用不另算，關閉後再請求會多算一次。
  • 點擊氣泡上的關閉（X），或者打開格子、插旗，提示就會關閉。

5. 輔助功能與盤面設定

在設定的操作和盤面中開關。遊戲中可以用快速設定馬上更改。

  • 點擊數字打開周圍（預設開啟）：點擊已打開的數字，如果周圍的旗子數與數字相同，就會打開其餘未打開的格子（見第3章）。關閉後，點擊數字沒有任何反應。
  • 立即顯示失誤（預設關閉）：馬上在插錯的旗子（插在不是地雷的格子上的旗子）上標出 X。困難模式不使用。關閉時，插錯的旗子要等提示指出才會告訴你。
  • 顯示時間（預設開啟）：在盤面上方顯示時間。關閉後只是不顯示，時間仍在計算。過關盤面的用時會顯示在結果裡。
  • 大號數字（預設關閉）：把盤面上的數字畫大一些。
  • 長按時間(毫秒)（預設 350）：從 250、300、350、400、500 中選擇。只在「點擊 · 長按」的操作方式下使用。

6. 模式

Classic — 自選等級，不限時

  • 在首頁 Classic 卡片上方的切換中選中 Classic，在分頁（1～5）中選擇等級，點擊開始。有進行中的盤面時會顯示繼續。第一次玩建議從等級1開始。
  • 等級依盤面大小（橫×縱）和地雷數劃分。等級越高，盤面越大，地雷越多。所有等級一開始就開放。

  • 分頁上顯示等級編號和盤面大小。卡片中間的盤面預覽顯示正在解的盤面的樣子（已打開的格子、旗子、踩到的地雷；不畫數字），向兩側滑動可以切換到下一個或上一個等級。下面一行顯示所選等級和一行紀錄（例如「等級3 · 12×16 · 地雷36」，「最佳 03:41 · 過關 12 · 完美 3」）。
  • 盤面會從還沒過關的盤面裡隨機出。過關過的盤面不會再出現；某個等級的盤面全部過關後，會從最早過關的那一局開始再出。
  • 過關後，結果卡片會顯示用時、失誤、提示、最佳（超過原來的紀錄時會蓋上新紀錄印章）和過關的盤面數。沒有失誤也沒有使用提示時會蓋上完美印章，有失誤時會提示「有失誤的盤面不計入最佳紀錄」。點擊下一局會接著出同一等級的下一局。
  • 進行中的盤面會自動儲存。離開或重新打開應用程式後，每個等級都能接著解。離開應用程式期間不計時。如果在打開起始格之前離開，同一個盤面會原樣等著你。

困難 — 踩到地雷就結束

  • 在首頁 Classic 卡片上方的[Classic | 困難]切換中選中困難，就用經典規則解同樣的五個等級（上表的盤面大小和地雷數）。選中困難後，所選等級的分頁和下面的按鈕會變成深色底、琥珀色邊框的困難樣式，按鈕變成挑戰（有進行中的盤面時為繼續）。Classic 和困難看的是同一個等級。
  • 踩到地雷，這一局就結束了（失敗）。所有藏著的地雷都會顯示出來，插錯的旗子上會有 X。結果會顯示「踩到地雷了」和已打開的安全格的比例。
  • 沒有提示。 盤面下方一行沒有提示按鈕，取而代之的是「踩到地雷就結束 · 沒有提示」的條。立即顯示失誤也不使用。點擊數字打開周圍仍然可用（旗子插錯時地雷會被打開，算失敗）。
  • 盤面數量沒有限制。點擊結果裡的下一局就能接著玩。在困難模式中結束的盤面（成功或失敗）不會再出現，在 Classic 中進行到一半的盤面也會盡量避開。
  • 中途離開不算失敗。每個等級正在解的盤面會儲存下來，之後可以接著解。
  • 重來面板裡只有新的一局（把同一局從頭開始，就會帶著已經看過的格子開始）。打開起始格之後選擇新的一局，這一局會記為失敗。 面板裡也這樣寫著。打開起始格之前不計。
  • 結果卡片會顯示最佳（只算成功的盤面，超過原來的紀錄時蓋上新紀錄印章）、連續成功、成功率和成功（成功的盤面/結束的盤面）。紀錄畫面裡也按等級彙總（見第7章）。分享只有 Daily 才有。

Daily — 今天的三個盤面

  • 每天所有人拿到同樣的三個盤面：小盤面（9×9 · 地雷10）、中盤面（12×16 · 地雷36）、大盤面（16×30 · 地雷99）。全世界的人在同一天解同樣的盤面（以裝置日期為準）。新的 Daily 會在裝置時間的午夜開放。
  • 每個盤面分開解，結果也各自儲存。規則和 Classic 一樣（失誤不會結束盤面，提示不限次數）。盤面不會以失敗告終，所以沒有失敗。
  • 沒有時間限制，到目前為止的用時顯示在盤面上方（可以在設定中隱藏）。
  • 當天之內離開再回來也能接著解。即使選擇這一局從頭開始，當天的用時、失誤和提示也會繼續累計（重來時只有這一項）。日期變了以後，沒解完的昨天的盤面會消失，新的盤面會開放。
  • 當天的三個盤面只要過關其中一個，這一天就計入連續；中間空一天就會中斷。
  • 首頁的 Daily 卡片會顯示編號和日期（例如 #12 · 10月22日）、連續天數、今天的三個盤面和這一週的七天。每個盤面的格子上顯示盤面名稱、大小和狀態（未開始、繼續，過關的盤面顯示打勾和用時），點擊後可以開始解，或查看已過關盤面的結果。這一週的七天顯示星期、日期和當天三個盤面的圓點（過關的盤面是實心圓點，今天是粗邊框）。
  • 結果畫面會顯示盤面大小、用時、失誤、提示、連續（天數）、這一週的七天和距下次 Daily 的時間。沒有失誤也沒有使用提示時會蓋上完美印章，超過最長連續時，連續一欄會蓋上新紀錄印章。可以用分享傳送結果（一次一個盤面）。例如：
Minewise Daily 小盤面 #12 ✅ 03:41
失誤 0 · 提示 1
🔥 連續5天

#12是 Daily 的編號，旁邊是用時（分:秒，超過一小時則為時:分:秒）。第一行的「Minewise Daily」在任何語言中都一樣，並寫上盤面種類，方便解同一個盤面的人互相比較。第二行是失誤和提示的次數，第三行是連續紀錄（兩天以上才顯示）。第一個 Daily 是 #1，之後每天加一，編號相同就是同樣的盤面。

  • Classic：各等級（盤面大小）的過關數、最佳用時（只計算沒有失誤的盤面）、平均用時和完美盤面數（沒有失誤也沒有使用提示的盤面）。還沒有過關的等級會變淡，用時顯示為「-」。
  • 困難：各等級的成功（成功的盤面/結束的盤面）、成功率、最佳用時（只算成功的盤面）和最佳連續（最長的連續成功）
  • Daily：連續、最長連續、過關天數、過關盤面。下方的月曆（用兩側的箭頭按月翻頁）會用實心圓標出過關的日子，今天會有邊框。

8. 設定

點擊首頁右上角的齒輪打開。分為四組。遊戲中可以用快速設定按鈕馬上更改前三組。

聲音與效果

項目內容
音效開關打開格子、插旗和拔旗、點擊數字打開周圍、踩到地雷、提示、盤面過關和結果印章等的聲音
震動插旗時短促，拔旗時更輕，踩到地雷時沉重，盤面過關時較長。可以開關
減少特效一次減少所有特效。開啟期間，下面的動畫、光效、彩紙都相當於關閉
動畫 · 光效 · 彩紙逐項開關特效。動畫是打開的波紋、插旗彈跳和拆除，光效是起始格的光、爆炸和過關的光，彩紙是結果畫面。沒有整個盤面晃動的特效

操作

項目內容
操作方式在點擊 · 長按（預設）和[打開|插旗]按鈕中選擇（見第3章）
長按時間(毫秒)從 250、300、350、400、500 中選擇。預設 350。只在點擊 · 長按時使用
點擊數字打開周圍周圍的旗子數與數字相同時，打開其餘的格子。預設開啟

盤面
