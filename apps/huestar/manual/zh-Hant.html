開發Willee Project
支援平台Android

Huestar 是一款在被分成顏色區域的盤面上，讓每一橫列、每一直行、每個區域都放上星星的邏輯謎題（Star Battle）。每個盤面都只有一個答案，不靠猜測、只靠邏輯就能解到最後。

  • 沒有生命值，也不統計失誤次數。提示不限次數、免費使用，也沒有時間限制。
  • 不需要註冊，也不需要登入。第一次打開時，會先用一個5×5的小盤面進行新手教學，帶你熟悉規則。點擊略過可以隨時結束。
  • 沒有網路也能玩。 只有畫面下方的廣告，以及傳送使用統計和錯誤報告時才會用到網路。
  • 語言跟隨裝置設定。支援中文（繁體、簡體）、英文、韓文、日文，也可以在設定中直接選擇。

1. 規則

  • 盤面是縱橫排列的方形格子，被粗線分成與橫列數相同數量的顏色區域。
  • 每個橫列、直行、區域各放一顆星。等級6（雙星盤面）則各放兩顆。
  • 星星之間不能相鄰。 不只是橫向、縱向，斜向相鄰的格子裡也不能同時放星星。
  • 所有星星都放對，就完成了。圓點不必打滿。把放錯的星星拿掉後正好與答案一致，也算完成。
  • 圓點是你自己的標記，表示「這裡不能放星星」。解題時並非必須，但把已經排除的格子標出來，剩下的格子會更容易看清。
  • 每個盤面都只有一個答案，不靠猜測、只靠邏輯就能解到最後。不會出現必須靠猜才能確定某個格子的盤面。
  • 沒有生命值，也不統計失誤。放錯星星，盤面也不會結束，復原不限次數。
  • 最佳用時只計算沒有使用提示的盤面。 不使用提示就解開時，結果上會蓋上完美印章。

盤面怎麼看

  • 每個區域都像寶石色的彩色玻璃一樣，塗著各自的顏色。區域之間是粗黑的鉛線，同一區域內的格子之間是細線。區域不只靠顏色來區分，也靠粗線來分隔。
  • 星星放滿的區域（沒有衝突的星星時）會像被光照到的玻璃一樣亮起來。
  • 顏色難以分辨時，請開啟設定中的區域花紋。每個區域都會疊上不同的線條花紋。
  • 規則衝突（預設開啟）：相鄰的星星會變成帶雙層圓環的紅色星星；星星過多，或剩下的格子放不下所需星星的橫列、直行、區域，會鋪上斜向條紋。只依據規則來提示，不參考答案。
  • 蓋著白光的橫列、直行、區域，以及帶柔光和虛線框的格子，是提示所指的地方（見第4章）。

2. 解題要點

新手教學用一個5×5的盤面教你基礎，分六步：區域 → 不能相鄰 → 打圓點 → 橫列 → 直行 → 獨立完成。每一步都會讓要看的地方亮起，只有該點擊的格子才有反應。提示會用名稱告訴你用了哪種要點。從最容易的開始，如下。

  • 星星周圍：星星周圍的八個格子裡不能放星星。
  • 已滿的橫列或直行、已滿的區域：星星已經放滿的橫列、直行、區域，剩下的格子裡不能放星星。
  • 剩下的格子：橫列、直行、區域裡還能放星星的格子，數量正好等於還需要的星星數時，這些格子全都是星星。
  • 都相鄰的格子：如果某個格子與某個橫列、直行或區域剩下的所有格子都相鄰，在這個格子裡放星星，那個橫列、直行或區域就沒有地方放星星了。所以這個格子裡不能放星星。
  • 受限的區域、受限的橫列或直行：如果一個區域剩下的格子都在同一個橫列（或同一個直行）裡，這個區域的星星就是那個橫列的星星。所以那個橫列的其他格子裡不能放星星（橫列和區域互換也一樣）。
  • 試放：試著在某個格子裡放星星，它的周圍，以及因此放滿的橫列、直行、區域裡剩下的格子都會被排除，結果某個橫列、直行或區域就沒有足夠的格子放星星了。所以這個格子裡不能放星星。
  • 兩條橫列或直行裡的兩個區域、兩個區域裡的兩條橫列或直行：把「受限」的想法擴大到兩個。如果兩個區域剩下的格子都在兩條橫列（或兩條直行）裡，這兩條橫列（或直行）的其他格子裡不能放星星。
  • 三個以上受限：同樣的想法，擴大到三個以上的區域。
  • 2×2方塊（雙星盤面）：如果橫列、直行、區域剩下的格子，可以用與還需要的星星數相同數量的2×2方塊蓋住，那麼每個2×2方塊裡正好有一顆星。

等級1的盤面用到試放為止就能解開。等級越高，越會出現需要用到擴大後的「受限」想法的盤面。更難的要點，會由提示連同理由一起告訴你（見第4章）。

3. 操作

  • 操作方式 A（預設）：每次點擊格子，會依 空白 → 圓點 → 星星 → 空白 切換。顯示著自動圓點的格子視為圓點，點擊後變成星星。
  • 操作方式 B：在設定的操作方式中選擇 B 點擊/長按 後，點擊放置或拿掉星星，長按放置或擦掉圓點。可以用盤面下方的 [圓點|星星] 互換點擊和長按的作用。長按時圓環會逐漸變滿，長按時間在設定中選擇（預設 350 毫秒）。
  • 拖動打圓點：在空白格子上拖動手指，經過的格子會打上圓點。從圓點開始拖動，會擦掉經過的圓點。只在盤面內有效。
  • 自動圓點（預設開啟）：放下星星後，星星周圍，以及星星已放滿的橫列、直行、區域裡剩下的格子，會自動打上圓點。它們看起來比你自己打的圓點稍小、稍淡，拿掉星星時會一起消失。
  • 復原：用盤面下方的復原取消最後一步操作。次數不限，一次拖動只需復原一次。
  • 手指抬起時才確定。如果有第二根手指碰到螢幕，這一次點擊會被丟棄。

4. 提示

提示按鈕會告訴你解題的下一步，並說明理由。提示不限次數，免費使用。

同一個按鈕要按三次：提示 → 查看 → 套用。

  • 第一步：點擊提示，只會告訴你要看的地方。作為依據的橫列、直行、區域會蓋上白光，內側還會加一圈邊框。氣泡上的名稱是所用的要點（見第2章）。例如：「看看亮起的區域剩下的格子在哪些橫列裡。」
  • 第二步：按鈕變成查看。點擊後，要確定的格子會出現柔光和虛線框，要放的星星顯示為淡淡的星星，要打的圓點顯示為淡淡的圓點，同時給出理由。理由裡不用顏色名稱或橫列、直行的編號，而是指向亮起的地方。
  • 第三步：按鈕變成套用。點擊後，會照此放上星星或打上圓點。復原一次即可還原。
  • 如果有錯誤的標記，會先指出它們（名稱錯誤的星星、錯誤的圓點）。不在答案裡的星星，以及打在答案星星所在格子上的圓點，會從最先放下的開始逐個指出。按鈕會直接變成套用，點擊後擦掉那個標記。
  • 當接下來有幾步都只是確定圓點時，點擊氣泡裡的直到下一顆星，就會一次打上這些圓點，並直接顯示接下來確定星星的那一步。
  • 提示只根據放對的星星，以及由它們推出的圓點來推理。你自己打的圓點不會被當作依據，所以即使一個圓點也沒打，或者圓點打錯了，提示也永遠是對的。盤面上已經全部看得到的步驟會被跳過。
  • 用過的提示次數會顯示在盤面上方一行和結果裡，也會寫進 Daily 的分享文字。請求提示時（第一步）算一次。查看和套用不另算，關閉後再請求會多算一次。直到下一顆星也只在新請求時才算。
  • 點擊氣泡上的關閉（X），或者點擊格子，提示就會關閉。沒有更多提示可以顯示時，會提示「沒有更多提示了」。

5. 輔助功能

在設定的盤面與操作和輔助功能中開關。遊戲中可以用快速設定馬上更改。

  • 自動圓點（預設開啟）：在星星周圍，以及星星已放滿的橫列、直行、區域裡自動打圓點（見第3章）。關閉後，只顯示你自己打的圓點。
  • 顯示規則衝突（預設開啟）：顯示相鄰的星星，以及星星過多或剩餘格子不夠放的橫列、直行、區域（見第1章）。
  • 立即顯示失誤（預設關閉）：馬上標出與答案不同的星星。關閉時，放錯的星星要等提示指出才會告訴你。
  • 顯示時間（預設開啟）：在盤面上方顯示時間。關閉後只是不顯示，時間仍在計算。解開的盤面的用時會顯示在結果裡。
  • 區域花紋（預設關閉）：給每個區域疊上不同的線條花紋（顏色難以分辨時）。
  • 長按時間(毫秒)（預設 350）：從 250、300、350、400、500 中選擇。只在操作方式 B 時顯示。

6. 模式

Classic — 自選等級，不限時

  • 在首頁的 Classic 卡片上，用等級分頁（1～6）選擇等級，點擊開始。有進行中的盤面時會顯示繼續。第一次玩建議從等級1開始。
  • 等級依盤面大小和星星數劃分。所有等級一開始就開放，每個等級有2,000個盤面。

  • 分頁上顯示等級編號和盤面大小，雙星盤面還會帶兩顆小星星。卡片中間的盤面預覽顯示正在解的盤面的樣子（已放的星星和圓點），向兩側滑動可以切換到下一個或上一個等級。下面一行顯示所選等級和一行紀錄（例如「等級3 · 8×8 · 1顆星」，「最佳 03:41 · 完成 12 · 完美 3」）。
  • 盤面會從還沒解開的盤面裡隨機選出，並經過旋轉或翻轉、重新搭配區域顏色後給出。解開過的盤面不會再出現；某個等級的盤面全部解開後，會從最早解開的那一局開始再次出現。
  • 解開盤面後，光會向外擴散兩次，然後出現結果卡片。上面有用時、提示、最佳（只算沒有使用提示的盤面；超過原來的紀錄時會蓋上新紀錄印章）和完成的盤面數。沒有使用提示就解開時會蓋上完美印章。點擊下一局會接著出同一等級的下一局。
  • 進行中的盤面會自動儲存。離開或關閉再打開應用程式後，每個等級都能接著解。打開盤面畫面後開始計時，離開應用程式或離開畫面期間不計時。沒有操作就離開的盤面不會留下用時，原樣等著你。

Daily — 今天的三個盤面

  • 每天所有人拿到同樣的三個盤面：小型盤面（6×6）、中型盤面（8×8）、大型盤面（10×10），都是單星盤面。全世界的人在同一天解同樣的盤面（以裝置日期為準）。新的 Daily 會在裝置時間的午夜開放。
  • 每個盤面分開解，結果也各自儲存。規則和 Classic 一樣（沒有生命值，提示不限次數）。
  • 沒有時間限制，到目前為止的用時顯示在盤面上方（可以在設定中隱藏）。
  • 當天之內離開再回來也能接著解。即使選擇這一局從頭開始，當天的用時和提示也會繼續累計（重來時只有這一項）。日期變了以後，沒解完的昨天的盤面會消失，新的盤面會開放。
  • 當天的三個盤面只要解開其中一個，這一天就計入連續；中間空一天就會中斷。
  • 首頁的 Daily 卡片會顯示Daily 編號和今天的日期、連續天數、今天的三個盤面和這一週的七天。每個盤面的格子上顯示盤面名稱、大小和狀態（新的一局、繼續，解開的盤面顯示星光色的格子和用時），點擊後可以開始解，或查看已解開盤面的結果。這一週的七天顯示星期、日期和當天三個盤面的星星（解開的盤面是實心星星，今天是粗邊框）。
  • 結果畫面會顯示盤面種類和大小、用時、提示、連續（天數）、今天解開的盤面數、這一週的七天和距下次 Daily 的時間。沒有使用提示就解開時會蓋上完美印章，超過最長連續時，連續一欄會蓋上新紀錄印章。可以用分享傳送結果（一次一個盤面）。例如：
Huestar Daily #12 · 中 ✅ 03:41
提示 0
🔥 連續5天

#12是 Daily 的編號，旁邊是盤面種類和用時（分:秒，超過一小時則為時:分:秒）。第一行的「Huestar Daily」在任何語言中都一樣。第二行是提示次數，第三行是連續紀錄（兩天以上才顯示）。盤面本身不會放進去，因為會洩露答案。第一個 Daily 開放的那天是 #1，之後每天加一，編號和盤面種類相同就是同樣的盤面。

7. 紀錄

點擊首頁右上角的獎盃按鈕打開。按鈕上會顯示完成的盤面數。

  • 最上方：完成的盤面（Classic 和 Daily）的合計，以及 Classic、Daily 各自的數量
  • Classic：各等級的完成數、最佳用時（只算沒有使用提示的盤面）、平均用時（所有盤面）和完美盤面數（沒有使用提示的盤面）。還沒有解開盤面的等級會變淡，用時顯示為「-」。
  • Daily：連續、最長連續、完成天數、完成。下方的月曆（用兩側的按鈕按月翻頁）上，解開的日子是星光色的格子，格子上按當天解開的盤面數加上星星，今天會有邊框。

8. 設定

點擊首頁右上角的齒輪打開。分為四組。遊戲中可以用快速設定按鈕馬上更改前三組。
