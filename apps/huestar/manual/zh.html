Huestar 是一款在被分成颜色区域的盘面上，让每一行、每一列、每个区域都放上星星的逻辑谜题（Star Battle）。每个盘面都只有一个答案，不靠猜测、只靠逻辑就能解到最后。

  • 没有生命值，也不统计失误次数。提示不限次数、免费使用，也没有时间限制。
  • 无需注册，也无需登录。第一次打开时，会先用一个5×5的小盘面进行新手教程，带你熟悉规则。点击跳过可以随时结束。
  • 没有网络也能玩。 只有屏幕下方的广告，以及发送使用统计和错误报告时才会用到网络。
  • 语言跟随设备设置。支持中文（简体、繁体）、英语、韩语、日语，也可以在设置中直接选择。

1. 规则

  • 盘面是纵横排列的方形格子，被粗线分成与行数相同数量的颜色区域。
  • 每行、每列、每个区域各放一颗星。等级6（双星盘面）则各放两颗。
  • 星星之间不能相邻。 不仅横向、纵向，斜向相邻的格子里也不能同时放星星。
  • 所有星星都放对，就完成了。圆点不必打满。把放错的星星拿掉后正好与答案一致，也算完成。
  • 圆点是你自己的标记，表示“这里不能放星星”。解题时并非必须，但把已经排除的格子标出来，剩下的格子会更容易看清。
  • 每个盘面都只有一个答案，不靠猜测、只靠逻辑就能解到最后。不会出现必须靠猜才能确定某个格子的盘面。
  • 没有生命值，也不统计失误。放错星星，盘面也不会结束，撤销不限次数。
  • 最佳用时只计算没有使用提示的盘面。 不使用提示就解开时，结果上会盖上完美印章。

盘面怎么看

  • 每个区域都像宝石色的彩色玻璃一样，涂着各自的颜色。区域之间是粗黑的铅线，同一区域内的格子之间是细线。区域不只靠颜色来区分，也靠粗线来分隔。
  • 星星放满的区域（没有冲突的星星时）会像被光照到的玻璃一样亮起来。
  • 颜色难以分辨时，请打开设置中的区域花纹。每个区域都会叠上不同的线条花纹。
  • 规则冲突（默认开启）：相邻的星星会变成带双层圆环的红色星星；星星过多，或剩下的格子放不下所需星星的行、列、区域，会铺上斜向条纹。只依据规则来提示，不参考答案。
  • 盖着白光的行、列、区域，以及带柔光和虚线框的格子，是提示所指的地方（见第4章）。

2. 解题要点

新手教程用一个5×5的盘面教你基础，分六步：区域 → 不能相邻 → 打圆点 → 行 → 列 → 独立完成。每一步都会让要看的地方亮起，只有该点击的格子才有反应。提示会用名称告诉你用了哪种要点。从最容易的开始，如下。

  • 星星周围：星星周围的八个格子里不能放星星。
  • 已满的行或列、已满的区域：星星已经放满的行、列、区域，剩下的格子里不能放星星。
  • 剩下的格子：行、列、区域里还能放星星的格子，数量正好等于还需要的星星数时，这些格子全都是星星。
  • 都相邻的格子：如果某个格子与某行、某列或某个区域剩下的所有格子都相邻，在这个格子里放星星，那一行、一列或一个区域就没有地方放星星了。所以这个格子里不能放星星。
  • 受限的区域、受限的行或列：如果一个区域剩下的格子都在同一行（或同一列）里，这个区域的星星就是那一行的星星。所以那一行的其他格子里不能放星星（行和区域互换也一样）。
  • 试放：试着在某个格子里放星星，它的周围，以及因此放满的行、列、区域里剩下的格子都会被排除，结果某一行、某一列或某个区域就没有足够的格子放星星了。所以这个格子里不能放星星。
  • 两行或两列里的两个区域、两个区域里的两行或两列：把“受限”的想法扩大到两个。如果两个区域剩下的格子都在两行（或两列）里，这两行的其他格子里不能放星星。
  • 三个以上受限：同样的想法，扩大到三个以上的区域。
  • 2×2方块（双星盘面）：如果行、列、区域剩下的格子，可以用与还需要的星星数相同数量的2×2方块盖住，那么每个2×2方块里正好有一颗星。

等级1的盘面用到试放为止就能解开。等级越高，越会出现需要用到扩大后的“受限”想法的盘面。更难的要点，会由提示连同理由一起告诉你（见第4章）。

3. 操作

  • 操作方式 A（默认）：每次点击格子，会按 空白 → 圆点 → 星星 → 空白 切换。显示着自动圆点的格子视为圆点，点击后变成星星。
  • 操作方式 B：在设置的操作方式中选择 B 点击/长按 后，点击放置或拿掉星星，长按放置或擦掉圆点。可以用盘面下方的 [圆点|星星] 互换点击和长按的作用。长按时圆环会逐渐变满，长按时间在设置中选择（默认 350 毫秒）。
  • 拖动打圆点：在空白格子上拖动手指，经过的格子会打上圆点。从圆点开始拖动，会擦掉经过的圆点。只在盘面内有效。
  • 自动圆点（默认开启）：放下星星后，星星周围，以及星星已放满的行、列、区域里剩下的格子，会自动打上圆点。它们看起来比你自己打的圆点稍小、稍淡，拿掉星星时会一起消失。
  • 撤销：用盘面下方的撤销取消最后一步操作。次数不限，一次拖动只需撤销一次。
  • 手指抬起时才确定。如果有第二根手指碰到屏幕，这一次点击会被丢弃。

顶部一行左侧显示模式名称和盘面（例如 Classic，等级3 · 8×8 和星星图案）。星星图案的数量就是每行、每列、每个区域要放的星星数（双星盘面显示 ★★）。Daily 显示 Daily 编号（#12）和盘面种类。右侧的按钮如下。

4. 提示

提示按钮会告诉你解题的下一步，并说明理由。提示不限次数，免费使用。

同一个按钮要按三次：提示 → 查看 → 采用。

  • 第一步：点击提示，只会告诉你要看的地方。作为依据的行、列、区域会盖上白光，内侧还会加一圈边框。气泡上的名称是所用的要点（见第2章）。例如：“看看高亮的区域剩下的格子在哪些行里。”
  • 第二步：按钮变成查看。点击后，要确定的格子会出现柔光和虚线框，要放的星星显示为淡淡的星星，要打的圆点显示为淡淡的圆点，同时给出理由。理由里不用颜色名称或行、列的编号，而是指向高亮的地方。
  • 第三步：按钮变成采用。点击后，会照此放上星星或打上圆点。撤销一次即可还原。
  • 如果有错误的标记，会先指出它们（名称错误的星星、错误的圆点）。不在答案里的星星，以及打在答案星星所在格子上的圆点，会从最先放下的开始逐个指出。按钮会直接变成采用，点击后擦掉那个标记。
  • 当接下来有几步都只是确定圆点时，点击气泡里的直到下一颗星，就会一次打上这些圆点，并直接显示接下来确定星星的那一步。
  • 提示只根据放对的星星，以及由它们推出的圆点来推理。你自己打的圆点不会被当作依据，所以即使一个圆点也没打，或者圆点打错了，提示也永远是对的。盘面上已经全部看得到的步骤会被跳过。
  • 用过的提示次数会显示在盘面上方一行和结果里，也会写进 Daily 的分享文字。请求提示时（第一步）算一次。查看和采用不另算，关闭后再请求会多算一次。直到下一颗星也只在新请求时才算。
  • 点击气泡上的关闭（X），或者点击格子，提示就会关闭。没有更多提示可以显示时，会提示“没有更多提示了”。

5. 辅助设置

在设置的盘面与操作和辅助设置中开关。游戏中可以用快捷设置马上更改。

  • 自动圆点（默认开启）：在星星周围，以及星星已放满的行、列、区域里自动打圆点（见第3章）。关闭后，只显示你自己打的圆点。
  • 显示规则冲突（默认开启）：显示相邻的星星，以及星星过多或剩余格子不够放的行、列、区域（见第1章）。
  • 立即显示失误（默认关闭）：马上标出与答案不同的星星。关闭时，放错的星星要等提示指出才会告诉你。
  • 显示时间（默认开启）：在盘面上方显示时间。关闭后只是不显示，时间仍在计算。解开的盘面的用时会显示在结果里。
  • 区域花纹（默认关闭）：给每个区域叠上不同的线条花纹（颜色难以分辨时）。
  • 长按时间(毫秒)（默认 350）：从 250、300、350、400、500 中选择。只在操作方式 B 时显示。

6. 模式

Classic — 自选等级，不限时

  • 在主页的 Classic 卡片上，用等级分页（1～6）选择等级，点击开始。有进行中的盘面时会显示继续。第一次玩建议从等级1开始。
  • 等级按盘面大小和星星数划分。所有等级一开始就开放，每个等级有2,000个盘面。
等级盘面大小每行、每列、每个区域的星星数
16×61颗
27×71颗
38×81颗
49×91颗
510×101颗
610×102颗
  • 分页上显示等级编号和盘面大小，双星盘面还会带两颗小星星。卡片中间的盘面预览显示正在解的盘面的样子（已放的星星和圆点），向两侧滑动可以切换到下一个或上一个等级。下面一行显示所选等级和一行记录（例如“等级3 · 8×8 · 1颗星”，“最佳 03:41 · 完成 12 · 完美 3”）。
  • 盘面会从还没解开的盘面里随机选出，并经过旋转或翻转、重新搭配区域颜色后给出。解开过的盘面不会再出现；某个等级的盘面全部解开后，会从最早解开的那一局开始再次出现。
  • 解开盘面后，光会向外扩散两次，然后出现结果卡片。上面有用时、提示、最佳（只算没有使用提示的盘面；超过原来的纪录时会盖上新纪录印章）和完成的盘面数。没有使用提示就解开时会盖上完美印章。点击下一局会接着出同一等级的下一局。
  • 进行中的盘面会自动保存。离开或关闭再打开应用后，每个等级都能接着解。打开盘面画面后开始计时，离开应用或离开画面期间不计时。没有操作就离开的盘面不会留下用时，原样等着你。

Daily — 今天的三个盘面

  • 每天所有人拿到同样的三个盘面：小型盘面（6×6）、中型盘面（8×8）、大型盘面（10×10），都是单星盘面。全世界的人在同一天解同样的盘面（以设备日期为准）。新的 Daily 会在设备时间的零点开放。
  • 每个盘面分开解，结果也各自保存。规则和 Classic 一样（没有生命值，提示不限次数）。
  • 没有时间限制，到目前为止的用时显示在盘面上方（可以在设置中隐藏）。
  • 当天之内离开再回来也能接着解。即使选择这一局从头开始，当天的用时和提示也会继续累计（重来时只有这一项）。日期变了以后，没解完的昨天的盘面会消失，新的盘面会开放。
  • 当天的三个盘面只要解开其中一个，这一天就计入连续；中间空一天就会中断。
  • 主页的 Daily 卡片会显示Daily 编号和今天的日期、连续天数、今天的三个盘面和这一周的七天。每个盘面的格子上显示盘面名称、大小和状态（新的一局、继续，解开的盘面显示星光色的格子和用时），点击后可以开始解，或查看已解开盘面的结果。这一周的七天显示星期、日期和当天三个盘面的星星（解开的盘面是实心星星，今天是粗边框）。
  • 结果画面会显示盘面种类和大小、用时、提示、连续（天数）、今天解开的盘面数、这一周的七天和距下次 Daily 的时间。没有使用提示就解开时会盖上完美印章，超过最长连续时，连续一栏会盖上新纪录印章。可以用分享发送结果（一次一个盘面）。例如：
Huestar Daily #12 · 中 ✅ 03:41
提示 0
🔥 连续5天

#12是 Daily 的编号，旁边是盘面种类和用时（分:秒，超过一小时则为时:分:秒）。第一行的“Huestar Daily”在任何语言中都一样。第二行是提示次数，第三行是连续记录（两天以上才显示）。盘面本身不会放进去，因为会泄露答案。第一个 Daily 开放的那天是 #1，之后每天加一，编号和盘面种类相同就是同样的盘面。

7. 记录

点击主页右上角的奖杯按钮打开。按钮上会显示完成的盘面数。

  • 最上方：完成的盘面（Classic 和 Daily）的合计，以及 Classic、Daily 各自的数量
  • Classic：各等级的完成数、最佳用时（只算没有使用提示的盘面）、平均用时（所有盘面）和完美盘面数（没有使用提示的盘面）。还没有解开盘面的等级会变淡，用时显示为“-”。
  • Daily：连续、最长连续、完成天数、完成。下方的日历（用两侧的按钮按月翻页）上，解开的日子是星光色的格子，格子上按当天解开的盘面数加上星星，今天会有边框。

8. 设置

点击主页右上角的齿轮打开。分为四组。游戏中可以用快捷设置按钮马上更改前三组。

9. 广告与记录的保存

  • 屏幕最下方有一条横幅广告。在新手教程中会撤下广告，只保留位置。广告只有这一条。游戏没有网络也能玩，网络只用于广告、使用统计和错误报告。
  • 应用内没有任何付费项目。
  • 记录和设置保存在设备中。如果开启了设备的 Google 备份（Android 自动备份），会一起备份，换设备后也能接着玩。卸载应用会删除设备中的记录。
  • 详情请参阅隐私政策。
