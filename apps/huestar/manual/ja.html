アプリについて

アプリ名Huestar
バージョン1.0.0
開発Willee Project
対応プラットフォームAndroid

色のエリアに分かれた盤面の、各行・各列・各エリアに星を置く論理パズル（スターバトル）です。どの盤面も答えは1つだけで、推測なしに論理だけで最後まで解けます。

  • ライフはなく、ミスの数も数えません。ヒントは回数無制限で無料、時間制限もありません。
  • 会員登録もログインもありません。初めて開くと、小さな盤面（5×5）でルールを覚えるチュートリアルから始まります。スキップでいつでも終えられます。
  • インターネットがなくても遊べます。 インターネットは画面下の広告と、利用統計・エラー報告の送信にだけ使います。
  • 言語は端末の設定に従います。日本語・英語・韓国語・中国語（簡体字・繁体字）に対応し、設定で直接選ぶこともできます。

1. ルール

  • 盤面は四角いマスが縦横に並び、太い線で区切られた色のエリアが、盤面の行数と同じ数だけあります。
  • 各行・各列・各エリアに星を1つずつ置きます。レベル6（星2つの盤面）は2つずつ置きます。
  • 星どうしは隣り合えません。 縦・横だけでなく、斜めに隣り合うマスにも星を一緒に置けません。
  • すべての星を正しく置けば完成です。点はすべて打たなくてもかまいません。間違った星を外して答えと同じになった場合も完成です。
  • 点は「ここには星が置けない」という自分用の印です。解くのに必須ではありませんが、星が置けないとわかったマスに印をつけておくと、残りのマスが見やすくなります。
  • どの盤面も答えは1つだけで、推測なしに論理だけで最後まで解けます。推測しないと決められないマスが出てくる盤面は出ません。
  • ライフはなく、ミスは数えません。間違った星を置いても盤面は続き、「元に戻す」は何回でも使えます。
  • ベストタイムはヒントなしでクリアした盤面だけを数えます。 ヒントなしで解くと、結果に完璧のスタンプが押されます。

盤面の見方

  • エリアはそれぞれ宝石のような色で、色ガラスのように塗られています。エリアの間は太い黒の鉛線、同じエリアの中のマスの間は細い線です。色だけでなく、太い線でもエリアを分けています。
  • 星が埋まったエリア（ぶつかった星がないとき）は、光を受けたガラスのように明るくなります。
  • 色の見分けがつきにくいときは、設定のエリアの模様をオンにしてください。エリアごとに違う線の模様が重なります。
  • ルール違反（最初はオン）: 隣り合った星は赤い星になって二重の輪が付き、星が多すぎる行・列・エリアや、残りのマスで星を置ききれなくなった行・列・エリアには、斜めの縞模様が付きます。ルールだけを見て知らせ、答えは見ません。
  • 白い光を重ねた行・列・エリアと、淡い光と点線の枠で囲んだマスは、ヒントが指しているところです（4章）。

2. 解き方のコツ

チュートリアルは、5×5の盤面1つで基本を教えます。エリア → 隣り合わない → 点を打つ → 行 → 列 → ひとりで解くの6段階で、段階ごとに見る場所を光らせ、決めるマスだけがタップできます。ヒントは使った考え方を名札で教えます。やさしいものから順に、次のとおりです。

  • 星の周り: 星の周りの8マスには星を置けません。
  • 埋まった行・列、埋まったエリア: 星が埋まった行・列・エリアの残りのマスには、星を置けません。
  • 残りのマス: 行・列・エリアで星を置けるマスが、まだ必要な星の数と同じだけしか残っていなければ、そのマスはすべて星です。
  • すべてに接するマス: ある行・列・エリアの残りのマスすべてに接するマスに星を置くと、その行・列・エリアに星を置くマスがなくなります。だから、そのマスには星を置けません。
  • 閉じ込められたエリア、閉じ込められた行・列: 1つのエリアの残りのマスがすべて1本の行（または列）の中にあれば、そのエリアの星がその行の星になります。だから、その行のほかのマスには星を置けません（行とエリアを入れ替えても同じです）。
  • 置いてみる: あるマスに星を置いてみると、その周りと、星が埋まる行・列・エリアの残りのマスが使えなくなり、どこかの行・列・エリアで星を置くマスが足りなくなります。だから、そのマスには星を置けません。
  • 2行・列に収まる2エリア、2エリアに収まる2行・列: 閉じ込められたエリアを2つに広げたものです。2つのエリアの残りのマスが2本の行（または列）の中にあれば、その行のほかのマスには星を置けません。
  • 3つ以上の閉じ込め: 同じ考え方を3つ以上のエリアに広げたものです。
  • 2×2ブロック（星2つの盤面）: 行・列・エリアの残りのマスを、まだ必要な星の数と同じ数の2×2ブロックで覆えるとき、2×2ブロックごとに星がちょうど1つです。

レベル1は置いてみるまでで解けます。レベルが上がるほど、閉じ込めを広げた考え方まで必要な盤面が出ます。難しい考え方は、ヒントが理由といっしょに教えてくれます（4章）。

3. 操作

  • 操作A（最初の設定）: マスをタップするたびに、空白 → 点 → 星 → 空白と変わります。自動の点が打たれたマスは点として扱われ、タップすると星になります。
  • 操作B: 設定の操作でB タップ・長押しを選ぶと、タップで星を置いたり外したり、長押しで点を打ったり消したりできます。盤面の下の「[点|星]」で、タップと長押しの役割を入れ替えられます。長押ししている間は輪が満ちていき、長押しの時間は設定で選びます（最初は350ms）。
  • なぞって点を打つ: 空白のマスの上を指でなぞると、通ったマスに点を打ちます。点からなぞり始めると、通った点を消します。盤面の中だけで受け付けます。
  • 自動の点（最初はオン）: 星を置くと、星の周りと、星が埋まった行・列・エリアの残りのマスに、自動で点が打たれます。自分で打った点より少し小さく淡く見え、星を外すと一緒に消えます。
  • 元に戻す: 盤面の下の元に戻すで、最後にした操作を取り消します。回数に上限はなく、1回のなぞりは1回で戻ります。
  • 指を離したときに決まります。指が2本触れると、そのタップは捨てられます。

画面上部の行の左には、モード名と盤面（例: Classic、レベル3 · 8×8と星の絵）が出ます。星の絵の数が、行・列・エリアごとに置く星の数です（星2つの盤面は★★）。DailyにはDailyの番号（#12）と盤面の種類が出ます。右のボタンは次のとおりです。

4. ヒント

ヒントボタンが、解き方の次の一歩を理由といっしょに教えます。ヒントは回数無制限で無料です。

同じ場所のボタンを3回押します。ヒント → 表示 → 適用です。

  • 1段目: ヒントを押すと、見る場所だけを教えます。根拠になる行・列・エリアに白い光が重なり、内側に枠が付きます。吹き出しの名札は使った考え方です（2章）。例:「ハイライトしたエリアの残りのマスが、どの行にあるか見てください。」
  • 2段目: ボタンが表示に変わります。押すと、決めるマスに淡い光と点線の枠が付き、置く星は薄い星、打つ点は薄い点で表示されて、理由が出ます。理由には色の名前や行・列の番号を使わず、ハイライトした場所を指して説明します。
  • 3段目: ボタンが適用に変わります。押すと、そのとおりに星を置くか点を打ちます。「元に戻す」1回で戻ります。
  • 間違った印があれば、それから教えます（名札間違った星、間違った点）。答えにない星や、答えの星のマスに打った点を、先に置いたものから指摘します。ボタンはすぐ適用になり、押すとその印を消します。
  • 点だけを決める段階が続くときは、吹き出しの次の星までを押すと、その点をまとめて打ち、次に星を決める段階をすぐに見せます。
  • ヒントは、正しく置かれた星と、そこから決まる点だけを根拠に考えます。自分が打った点は根拠に使わないので、点を1つも打っていなくても、点が間違っていても、ヒントは常に正しいです。すでに自分の盤面で全部見えている段階は飛ばします。
  • 使ったヒントの数は、盤面の上の行と結果に残り、Dailyのシェアの文にも入ります。ヒントを頼んだとき（1段目）に1回と数えます。表示と適用は別に数えず、閉じてからもう一度頼むと1回増えます。次の星までも、新しく頼むときだけ数えます。
  • 吹き出しの閉じる（×）を押すか、マスをタップすると、ヒントは閉じます。これ以上見せるヒントがないときは「これ以上のヒントはありません」と出ます。

5. アシスト機能

設定の盤面と操作とアシスト機能のグループでオン・オフします。ゲーム中はクイック設定ですぐに変えられます。

  • 自動の点（最初はオン）: 星の周りと、星が埋まった行・列・エリアに自動で点を打ちます（3章）。オフにすると、自分で打った点だけが見えます。
  • ルール違反を表示（最初はオン）: 隣り合った星と、星が多すぎる、または星を置くマスが足りない行・列・エリアを示します（1章）。
  • ミスをすぐ表示（最初はオフ）: 答えと違う星にすぐ印をつけます。オフのときは、間違った星はヒントが指摘するまで教えません。
  • 時間を表示（最初はオン）: 盤面の上に時間を表示します。オフにしても時間は数え続けます。解いた盤面のかかった時間は結果に出ます。
  • エリアの模様（最初はオフ）: エリアごとに違う線の模様を重ねます（色の見分けがつきにくいとき）。
  • 長押しの時間(ms)（最初は350）: 250・300・350・400・500から選びます。操作Bのときだけ出ます。

6. モード

Classic — レベルを選ぶ、時間制限なし

  • ホームのClassicカードで、レベルのタブ（1〜6）からレベルを選び、プレイを押します。途中の盤面があれば続きからになります。初めてならレベル1がおすすめです。
  • レベルは盤面の大きさと星の数で分かれます。レベルは最初からすべて選べて、レベルごとに盤面が2,000個あります。
レベル盤面の大きさ行・列・エリアごとの星
16×61つ
27×71つ
38×81つ
49×91つ
510×101つ
610×102つ
  • タブにはレベルの番号と盤面の大きさが出て、星2つの盤面には小さな星が2つ付きます。カード真ん中の盤面プレビューは今解いている盤面の様子（置いた星と点）で、横にスワイプすると次・前のレベルに切り替わります。その下に選んだレベルと記録の行が出ます（例:「レベル3 · 8×8 · 星1つ」、「ベスト 03:41 · クリア 12 · 完璧 3」）。
  • まだ解いていない盤面の中からランダムに出て、盤面を回転したり反転したりして、エリアの色も入れ替えて出します。解いた盤面は出ず、そのレベルの盤面をすべて解いたら、いちばん前に解いた盤面からまた出ます。
  • 盤面を解くと、光が2度広がってから結果カードが出ます。かかった時間、ヒント、ベスト（ヒントなしで解いた盤面だけ。前の記録を超えると新記録のスタンプ）、クリアした盤面の数が出ます。ヒントなしで解くと完璧のスタンプが押されます。次の盤面を押すと、同じレベルの次の盤面に進みます。
  • 解いている盤面は自動で保存されます。抜けても、アプリを閉じて開き直しても、レベルごとに続きから解けます。時間は盤面の画面を開くと進み、アプリを離れている間や画面を離れている間は進みません。手を付けずに抜けた盤面は、時間も残さず、そのまま待っています。

Daily — 今日の盤面3つ

  • 毎日、全員が同じ3つの盤面を受け取ります。小さな盤面（6×6）、中くらいの盤面（8×8）、大きな盤面（10×10）で、すべて星1つの盤面です。世界中のみんなが同じ日に同じ盤面を解きます（端末の日付が基準）。新しいDailyは端末の時刻で午前0時に開きます。
  • 盤面ごとに別々に解き、結果も盤面ごとに残ります。ルールはClassicと同じです（ライフはなく、ヒントは無制限）。
  • 時間制限はなく、これまでにかかった時間が盤面の上に出ます（設定で隠せます）。
  • その日のうちなら、抜けても続きから解けます。この盤面を最初からにしても、その日の時間・ヒントはそのまま数えます（やり直す画面にはこれだけがあります）。日付が変わると、解きかけの前日の盤面は消えて、新しい盤面が開きます。
  • その日の3つの盤面のうち1つでも解けば、その日が連続につながり、1日空けると途切れます。
  • ホームのDailyカードには、Dailyの番号と今日の日付、連続の日数、今日の3つの盤面、今週の7日が出ます。3つの盤面のマスには、盤面の名前・大きさと状態（新しい盤面、続きから、解いた盤面は星明かりのマスとかかった時間）が出て、押すと盤面を解くか、解いた盤面の結果が見られます。今週の7日には、曜日と日付、その日の3つの盤面の星が出ます（解いた盤面は塗りつぶした星、今日は太い枠）。
  • 結果画面には、盤面の種類と大きさ、かかった時間、ヒント、連続（日数）、今日解いた盤面の数、今週の7日、次のDailyまでの時間が出ます。ヒントなしで解くと完璧のスタンプが押され、最長の連続を超えると連続のマスに新記録のスタンプが押されます。シェアで結果を送れます（盤面ごとに別々）。例:
Huestar Daily #12 · 中 ✅ 03:41
ヒント 0
🔥 5日連続

#12はDailyの番号で、その隣は盤面の種類とかかった時間（分:秒。1時間を超えると時:分:秒）です。1行目の「Huestar Daily」はどの言語でも同じです。2行目はヒントの数、3行目は連続記録です（2日以上のときだけ）。盤面の絵は答えがわかってしまうので入れません。番号は最初のDailyが開いた日が#1で、1日ずつ増えるので、番号と盤面の種類が同じなら同じ盤面です。

7. 記録

ホーム右上のトロフィーボタンで開きます。ボタンにはクリアした盤面の数が出ます。

  • いちばん上: クリアした盤面（Classic・Daily）の合計と、ClassicとDailyに分けた数
  • Classic: レベルごとのクリア数、ベストタイム（ヒントなしで解いた盤面だけ）、平均タイム（すべての盤面）、完璧な盤面の数（ヒントなしで解いた盤面）。まだクリアした盤面がないレベルは薄く表示され、時間は「-」です。
  • Daily: 連続、最長連続、クリア日数、クリア。下のカレンダー（両わきのボタンで1か月ずつ切りかえます）で、解いた日は星明かりのマスにその日解いた盤面の数だけ星が付き、今日には枠が付きます。

8. 設定

ホーム右上の歯車で開きます。グループは4つです。ゲーム中はクイック設定ボタンで、前の3つのグループをすぐに変えられます。

9. 広告と記録の保管

  • 画面のいちばん下にバナー広告が一本入ります。チュートリアルでは広告を外し、場所だけ空けておきます。広告はこの一本だけです。ゲームはインターネットがなくても遊べ、インターネットは広告と利用統計・エラー報告にだけ使います。
  • アプリ内で支払うものはありません。
  • 記録と設定は端末の中に保存されます。端末のGoogleバックアップ（Androidの自動バックアップ）がオンなら一緒にバックアップされ、端末を替えても続きから遊べます。アプリを削除すると端末の記録も消えます。
  • 詳しくはプライバシーポリシーをご覧ください。
