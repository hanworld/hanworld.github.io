隐私政策

棋盘游戏

生效日期：2026-10-16

一目了然

  • 无需注册，无需登录，没有账号。
  • 开发者不会询问也不会接收您的姓名、邮箱等个人信息，也没有服务器。
  • 离开设备的只有两样：屏幕底部的横幅广告（Google AdMob），以及用于改进应用的使用统计和错误报告（Google Firebase）。
  • 游戏记录只留在设备内。您玩了哪些游戏、怎么下的棋，不会被发送到任何地方。
  • 在欧洲经济区（EEA）、英国和瑞士，我们会在展示广告前征求您的同意，您的选择也同样适用于使用统计。

1. 谁在处理

数据控制者Willee Project
应用棋盘游戏 (net.willee.boardgames)
联系方式hanworld@willee.net

2. 开发者收到的信息 — 没有个人信息

这个应用没有服务器。 我们不会询问您的姓名、邮箱、电话、通讯录、照片或精确位置，您怎么下棋也不会传到开发者这里。

开发者能看到的只有 Google Firebase 中的使用统计和错误报告（第4节）。其中同样没有姓名或联系方式，开发者只在 Firebase 控制台中以统计数字和错误列表的形式查看。

只保存在设备内的内容

是什么内容保存在哪何时删除
最近玩过的游戏游戏标识的列表（如 omok、checkers）设备内部存储卸载应用时一并删除

它只用于一件事：把您最近玩过的游戏排到大厅上方。它无法识别任何人，而且从不离开您的设备。

此外，广告 SDK（Google）会在设备上保存同意记录（如在欧洲地区所作的广告同意选择）以及广告所需的标识符；Firebase SDK 会在设备上暂存应用实例 ID 以及尚未发送的使用统计和错误报告。开发者无法查看设备上保存的这些内容。

3. 广告（Google AdMob）

屏幕最下方有一条横幅广告，由 Google AdMob 投放。为此，Google 及其广告合作伙伴会处理以下信息。

处理什么用于什么
广告 ID（Android 广告 ID）、应用组 ID，以及（如适用）与设备上已登录账号相关的标识符投放广告、控制展示频次、衡量效果；数据分析；防止欺诈与滥用；在您同意时用于个性化
IP 地址投放广告；根据 IP 推测的大致位置（国家/城市级别）
设备与应用信息（机型、系统版本、语言、屏幕尺寸、应用版本）挑选适合屏幕的广告；防止欺诈与滥用
广告互动（展示、点击）衡量效果；防止无效点击
应用使用信息（应用启动、点按、视频观看等互动）投放广告、衡量效果；数据分析；防止欺诈与滥用
诊断信息（应用启动时间、卡顿率、耗电量等性能信息）投放广告；分析应用与广告 SDK 的性能；防止欺诈与滥用

开发者不会收到其中任何一项。 Google 也会作为独立的数据控制者处理这些信息。详情请参阅 Google 的文档。

  • Google 隐私权政策
  • Google 如何使用来自使用我们服务的网站或应用的信息

4. 使用统计和错误报告（Google Firebase）

应用只把改进应用所需的以下信息发送到 Google Firebase。不会发送姓名、邮箱等个人信息，也不会发送游戏记录（玩了哪些游戏、怎么下的棋）。

4.1 使用统计 — Google Analytics for Firebase

处理什么例子用于什么
应用实例 ID安装应用时生成的随机 ID统计同一台设备是否再次使用（留存率）
应用使用应用启动、使用时长、应用更新、广告展示了解留存率和使用时长
设备与应用信息机型、Android 版本、应用版本、语言、国家（根据 IP 地址推测；不保存 IP 地址本身）发现特定机型的问题，了解各语言的使用情况
  • 使用统计不使用您的广告 ID。 广告 ID 只用于 Google AdMob 广告（第3节）。
  • 按用户的记录会在2个月后自动删除（Google Analytics 数据保留设置）。之后只留下无法对应到任何人的汇总数字。
  • 在欧洲经济区、英国和瑞士，您在首次打开应用时出现的同意窗口（第5节）中所作的选择，同时适用于广告和使用统计。

4.2 错误报告 — Firebase Crashlytics

处理什么用于什么
出错的代码位置（堆栈跟踪）、出错时间修复错误
机型、Android 版本、应用版本、内存与存储空间状态找出哪些设备受到影响
Crashlytics 安装 ID（随机 ID）统计同一错误在多少台设备上发生

错误报告会在90天后自动删除。

Google 代表开发者在 Google 的服务器上处理这些信息，包括韩国和欧洲经济区以外的地区（例如美国）。详情请参阅 Firebase 中的隐私与安全。

4.3 与广告的关联

使用统计已与广告（Google AdMob）关联，开发者会把广告收入与使用指标（用户数、回访等）放在一起查看。Google 可能会用关联的使用统计来改进 AdMob 的功能、提高广告收入。这里同样不使用广告 ID。

5. 同意 — 给予、更改、撤回

如果您身处欧洲经济区、英国或瑞士，首次打开应用时会出现同意窗口，通过 Google 认证的同意管理工具（UMP）向您征求。您的选择同时适用于广告和使用统计。

  • 如果您同意 — 可能会看到根据兴趣定制的个性化广告。
  • 如果您不同意 — 应用照常使用，功能一样不少。广告会变成非个性化的，使用统计的保存也会受到限制。但请注意，即便如此，为了投放广告、避免同一广告出现过于频繁以及防止欺诈，仍会处理最少量的信息（IP 地址、大致位置、设备信息、广告标识符等）。“非个性化”不等于“什么都不处理”。

错误报告（4.2）不受这一选择影响，照常发送，因为修复应用的卡死和错误需要它（第6节）。

如果您改变主意

在哪里怎么做
在应用中大厅右上角的应用信息（ⓘ）→ 广告同意 — 随时重新打开同意窗口并更改您的选择
在设备上Android 设置 → 隐私 → 广告 → 重置或删除广告 ID
彻底停止卸载应用，设备上的游戏记录和应用实例 ID 也会一并消失

6. 处理的法律依据（GDPR 第6条）

处理什么依据
个性化广告同意（第6条第1款(a)项）。通过上述同意窗口取得。
非个性化广告、防欺诈、广告投放依所在地区法律，为同意或正当利益（第6条第1款(f)项）
使用统计、错误报告正当利益（第6条第1款(f)项）：为了修复应用的错误并改进应用，也包括为了以广告运营免费应用，而把广告收入与使用指标放在一起查看。使用统计的保存会依您在同意窗口中的选择受到限制。
设备内的游戏记录不会传到开发者处，因此开发者一方不存在处理行为

7. 跨境传输

开发者没有服务器，因此没有数据被传输到开发者的服务器。

  • 使用统计和错误报告 — 由 Google LLC 代表开发者在 Google 的服务器（包括美国）上处理。在您使用应用期间通过网络随时发送，第4节中的项目按第4节所述的期限保存。
  • 广告 — Google 在投放广告的过程中，可能会将数据传输至欧洲经济区之外（包括美国）。

Google 声明其依据欧盟标准合同条款（SCC）等法律认可的传输机制进行。详情请参阅上方 Google 和 Firebase 的文档。

8. 保存多久

  • 开发者 — 没有服务器，自己不保存任何东西。
  • 使用统计和错误报告（Firebase） — 使用统计中按用户的记录在2个月后、错误报告在90天后自动删除。
  • 设备内 — 直到您卸载应用。
  • 广告（Google） — 遵循 Google 自己的保存政策。请参阅上方 Google 的文档。

9. 您的权利

如果您身处欧洲经济区或英国，GDPR（第15至22条）赋予您以下权利：

  • 访问、更正、删除
  • 限制处理、反对处理
  • 数据可携
  • 随时撤回同意（撤回之前的处理仍然有效）
  • 向监管机构投诉

该向谁提出。 与广告有关的数据，需要向真正持有数据的 Google 提出（参见 Google 隐私权政策）。至于使用统计和错误报告，开发者并不知道您的姓名或联系方式，因此无法找出特定用户的记录。卸载应用后，应用实例 ID 随之消失，之后的记录不会再与之前的记录相连，剩下的记录也会在上述保存期限届满后删除。如果您不确定该找谁，请写信到 hanworld@willee.net，我们会尽力为您指路。

投诉。 身处欧洲经济区的用户可向所在国的数据保护监管机构投诉；身处英国的用户可向信息专员办公室（ICO）投诉。

10. 儿童

本应用不面向儿童。 在 Google Play 上按面向 13 岁及以上用户登记。开发者不会在知情的情况下收集儿童的个人信息。

如果您是 16 岁以下（依成员国不同为 13 至 16 岁）儿童的家长或监护人，对孩子使用本应用有所顾虑，请写信到 hanworld@willee.net。

11. 政策变更

如果我们修改本政策，会连同新的生效日期一并发布在本页面。重大变更时也会通过应用的更新说明告知。
