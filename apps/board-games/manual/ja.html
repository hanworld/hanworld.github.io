アプリについて

アプリ名ボードゲーム (Board Games)
バージョン1.0.0
開発Willee Project
対応プラットフォームAndroid

七つのボードゲームを一つのアプリに。一人ならAIと、二人なら一台で。

  • 会員登録もログインもありません。開いたらすぐ遊べます。
  • インターネットがなくても対局できます。 ネットは画面下の広告を取ってくるときだけ使います。
  • 言語は端末の設定に従います。日本語・韓国語・英語・中国語(簡体字)に対応しています。

1. ゲームを選ぶ

アプリを開くとロビーが出ます。ゲームのカードが縦に並んでいます。カードを押すと、そのゲームのルールとともに対局設定が下から上がってきます。

最近遊んだゲームが上に来ます。 ただし実際に一手でも打ったゲームだけを数えます — 開いてルールを読んだだけで戻れば、並び順は変わりません。

2. 対局の設定

選ぶもの値説明
対戦相手AIと対戦 / 二人で「二人で」は一台の端末を交代で使う方式です。
難易度やさしい / ふつう / むずかしいAIと対戦するときだけ出ます。
先手自分が先手 / AIが先手AIと対戦するときだけ出ます。

開始を押すと盤が開きます。

3. 対局画面の見方

画面は上から下へ四段です。

1. 対局者の二枠

いちばん上に並ぶ二つの枠です。手番の側が明るく灯ります。 ゲームによっては点数も並びます。

ゲーム数字の意味
オセロ今の自分の石の数
チェッカーまだ残っている自分の駒の数
バックギャモン盤の外へ上げた駒の数
ドット＆ボックス取った箱の数

五目並べ・コネクトフォー・三目並べには数えるものがないので、数字は出ません。

2. 状態表示

今なにが起きているかを伝えます: 自分の番、AIが考え中…、サイコロを振っています…。ルール上の出来事があると、金色の文字が前に付きます。

金色の文字意味
置ける場所がなく手番を飛ばしました(オセロ) 置ける場所がなく、手番が飛ばされました
連続ジャンプ(チェッカー) 着地した場所からさらに取り続けなければなりません
バーに駒があります(バックギャモン) バーの駒を先に戻さなければなりません

3. 盤

中央。ここをタップして打ちます。

4. 待った・やり直す

下の二つのボタン。次の節で説明します。

対局が終わると結果の画面が盤を覆います。勝敗と点数が出て、ロビーへ戻るか、やり直すで同じ設定のままもう一局打てます。

4. 待ったとやり直し

待った — 自分が選ぶ番まで巻き戻します。AIの応手も一緒に取り消されます。戻る先の自分の番がなければボタンは押せません。

サイコロは戻せません。 バックギャモンの「待った」は、サイコロを振った地点より前へは戻りません。気に入らない目が出るたびに戻して振り直せるなら、それは待ったではなくズルです。

やり直す — 盤を最初から並べ直します。設定(対戦相手・難易度・先手)はそのままです。

5. 七つのゲーム

五目並べ — 先に五つ並べた方が勝ち

交互に交点へ石を置きます。縦・横・斜めのいずれかで先に五つ並べた方が勝ちです。禁じ手なしの自由ルールなので、六つ以上並んでも勝ちになります。

二度タップで確定します。 盤の目が細かく、指では一度に正確に狙えません。一度タップして位置を決め、同じ場所をもう一度タップして確定します。別の場所を押すと狙いがそちらへ移ります。

オセロ — 返して返されて、多い方が勝ち

自分の石と自分の石で相手の石を挟むように置くと、挟まれた石がすべて自分の色に返ります。返せない場所には置けません。

置ける場所がまったくない場合は手番を飛ばします(状態表示に置ける場所がなく手番を飛ばしましたと出ます)。両者とも置けなくなれば対局は終わり、石の多い方が勝ちです。

チェッカー — 跳び越えて取り、最奥で王になる

駒は斜め前に一マスずつ進みます。相手の駒を跳び越すと取れます。

取れるときは必ず取らなければならず、着地した場所からさらに取れるなら続けて跳びます(状態表示に連続ジャンプと出ます)。相手陣の最終列に届くとキングになり、後ろへも進めます。

相手の駒をすべて取るか、相手を動けなくすれば勝ちです。

バックギャモン — 先にすべての駒を上げた方が勝ち

サイコロを振り、出た目の数だけ駒を進めます。使える目はできる限り使い切らなければならず、ゾロ目(ダブル)なら四回動かせます。

相手の駒が一つだけの地点に乗ると、その駒はバーに送られます。バーの駒を盤に戻すまで、ほかの駒は動かせません(状態表示にバーに駒がありますと出ます)。

自分の駒十五個をすべてホームボードに集めると、盤の外へ上げ始められます。先に十五個すべて上げた方が勝ちです。

バックギャモンにはボタンが二つ増えます。
戻す — この手番で動かした分だけを取り消します(手番を確定する前まで)。
パス — 出た目でどこにも動かせないときだけ現れます。

コネクトフォー — 落として先に四つ並べたら勝ち

列を選んで石を落とします。石は重力に従い、その列のいちばん下の空きマスに積まれます。縦・横・斜めのいずれかで先に四つ並べた方が勝ちです。盤が埋まっても並ばなければ引き分けです。

ドット＆ボックス — 箱を多く取った方が勝ち

交互に隣り合う二つの点を線で結びます。箱の四辺目を引いた人がその箱を取り、続けてもう一度打てます。 箱を多く取った方が勝ちです。

三目並べ — 先に三つ並べた方が勝ち

交互に空いているマスへ印を置きます。縦・横・斜めのいずれかで自分の印を先に三つ並べた方が勝ちです。

6. 言語

端末の言語設定にそのまま従います。 アプリの中に言語を選ぶ場所はありません。

日本語・韓国語・英語・中国語(簡体字)に対応しています。端末がそれ以外の言語なら英語で表示されます。端末に複数の言語を登録している場合は、上から順に見て最初に合ったものを使います。

7. 広告とプライバシー

画面のいちばん下にバナーが一本入ります。ロビーでも対局中でも同じ一本です。

ヨーロッパなどにお住まいの方には、初めて開いたときに広告の同意画面が出ます。同意されなくても、アプリの機能はまったく同じようにお使いいただけます。

このアプリに会員登録もアカウントもなく、開発者は個人情報を一切収集しません。詳しくはプライバシーポリシーをご覧ください。
